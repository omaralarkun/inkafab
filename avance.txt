> Archivo de progreso generado en la sesión actual de opencode para poder reanudar contexto futuro.

## Qué es
Aplicación web **estática** (HTML + CSS + JS + JSON/CSV) de venta de impresión 3D:
- Catálogo de modelos.
- Analizador **STL/OBJ/3MF**: volumen → peso → precio, vista previa 3D (canvas propio).
- Carrito persistente (localStorage) con **+ / − / Eliminar**.
- **Pedido mínimo S/.50** con barra de progreso y checkout bloqueado.
- **IGV 18%** calculado internamente (no se muestra al cliente).
- Envíos **Serpost/Olva** + delivery Juliaca + recojo.
- Checkout por **WhatsApp**.
- Panel admin (CRUD + exportar/importar JSON/CSV + ventas locales ofuscadas).

## Motor de precio (calculateQuote en app.js)
```
factor = materialFactor(infill)               // 15→0.30, 30→0.42, 50→0.58, 100→1.00
pesoEstimado = volumenCm3 * densidad * factor
tiempoHoras  = (volumenMaterial) / velocidad
costoMaterial    = pesoG * precioG
costoElectricidad= potenciaKW * tiempoH * precioKWh * qty
costoMaquina     = tiempoH * costoMaquinaHora * qty
costoManoObra    = max(manoObraMinima, minutosPrep * tarifaManoObraMin)
costoBase        = suma de costos
precioUnitFinal (con IGV) = totalConIgv / qty
totalConIgv      = costoBase*(1+margen) * (1+igv)  [y precio mínimo]
```
- El IGV y el margen se calculan internamente; la UI solo muestra **Precio unidad** (ya con IGV), Cantidad y **TOTAL**.
